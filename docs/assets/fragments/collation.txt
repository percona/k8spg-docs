5. Scan for indexes that rely on collations other than `C` or `POSIX` and whose collations were provided by the operating system (`c`) or dynamic libraries (`d`). [Connect to PostgreSQL](connect.md) with the privileges of the superuser or the database owner and run the following query:

    ```sql
    SELECT DISTINCT
        indrelid::regclass::text,
        indexrelid::regclass::text,
        collname,
        pg_get_indexdef(indexrelid)
    FROM (
        SELECT
            indexrelid,
            indrelid,
            indcollation[i] coll
        FROM
            pg_index,
            generate_subscripts(indcollation, 1) g(i)
    ) s
    JOIN pg_collation c ON coll = c.oid
    WHERE
        collprovider IN ('d', 'c')
        AND collname NOT IN ('C', 'POSIX');
    ```

7. Refresh collation metadata and rebuild affected indexes. This command requires the privileges of a superuser or a database owner:

    ```sql
    ALTER DATABASE cluster1 REFRESH COLLATION VERSION;
    ```
